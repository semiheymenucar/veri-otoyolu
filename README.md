# Veri Otoyolu 🚀

Akıllı medya oynatıcı ve yükleme kota düşümü özelliklerine sahip Python tabanlı web uygulaması.

## Özellikler
- **Akıllı Medya Oynatıcı:** Medya akışını optimize eden özel şablon yapısı (`sablon.py`).
- **Kota Düşümü:** Yükleme sırasında veri tasarrufu sağlayan akıllı sıkıştırma/kota yönetimi.

## Kurulum ve Çalıştırma

1. Gerekli kütüphaneleri yükleyin:
```bash
pip install -r requirements.txt
```

2. Uygulamayı başlatın:
```bash
python app.py
```
